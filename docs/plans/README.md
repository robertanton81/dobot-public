# Implementation history

The dated files here record plans, proposals and execution notes. They stay in Git to explain
how the implementation developed. Their status notes and checkboxes describe the work at the
time they were written; they are not a current instruction to execute the plan again.

Outstanding work is tracked in a private backlog that this snapshot does not include. Use the
[documentation guide](../README.md)
to find current behavior, decisions and verification results.
